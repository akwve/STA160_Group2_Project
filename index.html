📌 About the Project

This project was created as a part of the class, STA160, to demonstrate statistical analysis, model building, and front to back end pipeline. We used 2 machine learning models to predict whether or not a news article or tweet was true or false and compared our models’ predictions to ChatGPT. The intention is for the user to input text in the appropriate place for a tweet or news article and receive output that shows the model’s truth value prediction as well as ChatGPT’s. From there, the user can make a more educated decision about whether to trust what they’ve read online.

🧪 Methods

Our project uses multiple data，machine learning model and AI tools to accurately identify fake information. Here are the main steps and models we used:

  1. Data Analysis and Preparation (EDA)：
    For the prediction model on Tweets, we used a dataset called “Truth Seeker 2023” from the Canadian Institute of Cybersecurity under University of New Brunswick. This dataset was initially gathered on 180,000 tweets from 2016-2017, particularly about news and politics. （need more "method" for XGBoost）！！！
  2. Model Selection and Baselines:
    To choose the best model, we explored logistic regression, XGBoost, Random Forest and BERT . Finally，We choose BERT for tweets and XGBoost for news BERT is designed to understand natural language directly. Instead of depending on outside information, BERT reads the full text of each tweet and learns meaning from context, sentence structure, and the way ideas are expressed. （need more "method" for XGBoost）！！！
  3. ChatGPT Prediction:
    We developed a Python script and a specific prompt designed to query ChatGPT when a user inputs text. The goal is to obtain an equivalent True or False prediction along with a confidence level. Unlike BERT and XGBoost, which are directly trained on our dataset,ChatGPT relies on its own general knowledge and language understanding.
  4. API Development and Cloud Deployment:
    Framework: The prediction service is built using Python Flask. Model Integration: The API integrates and hosts all three core models: BERT, XGBoost, and the ChatGPT. We create Two distinct public routes to serve the models based on the prediction category. /predict: Returns the BERT prediction and the independent ChatGPT prediction. /predict_xgb: Returns the XGBoost prediction and the independent ChatGPT prediction. To ensure reliable web access, including robust Cross-Origin Resource Sharing (CORS) allow requests from our GitHub Pages frontend. Finally, the service is deployed to Amazon Web Services (AWS).We used AWS API Gateway, It takes the requests from the website and sends them to our running service, and then sends the prediction results back instantly.
